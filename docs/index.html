Tetorica Retro Player

Images, videos, and screen capture are pushed through the same retro CRT/PC filter pipeline, with lo-fi retro audio effects to match. Build a playlist, send files over from your phone with mDrop, set an alarm, and record the filtered output — all from one desktop app (macOS / Windows / Linux), an Android app, a Chrome extension, or the browser demo below.

Open PWA Demo Read the Manual Open Chrome Extension View Source View Itch (Desktop, Android)
Input Drag and drop image or video files, or capture a screen or window.
Output Palette quantization, monochrome tinting, dithering, scanlines, and CRT mood.

What You Can Try In The Demo

Start with a photo, a clip, or a captured app window, then move between PC-98 style color limits, monochrome terminal looks, CRT/phosphor finishing, and lo-fi audio effects. Load multiple files as a playlist, save your favorite look as a settings file, and pick up the full manual for anything the demo doesn't cover.

Retro Video Filters Palette presets, monochrome tints, dithering, CRT curvature, scanlines, phosphor dots, and more — all tunable in real time.
Lo-Fi Audio Effects Bit crush, wow & flutter, tape saturation, vinyl noise, reverb, and a 3-band EQ to match the retro look.
mDrop & Playlists Send files in from your phone over the local network (desktop app), or queue up several files as a looping playlist.
