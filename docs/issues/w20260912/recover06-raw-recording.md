# Native / FX OFF での本体録画

## 動作

- Native mode または Audio FX OFF の共有ストリーム録音は、元ストリームの音声を直接cloneする。本体のモニター音量・ミュート・エフェクト出力には依存しない。素録りでは音声エンジンの初期化も不要。
- Native mode または映像フィルターOFFでは、共有元の映像トラックを直接録画する。映像フィルターONでは従来どおりcanvasを録画する。
- ストリームは再生要素のsrcObjectを優先し、保持中のstreamRefをフォールバックにする。終了済みトラックは選ばない。
- Audio FX OFFの通常メディアをWebAudioで再生している場合、入力ノードから録音用の分岐を作る。音量・ミュート・エフェクトより前から取り出し、スピーカー出力は追加しない。
- Nativeの通常メディアはメディア要素のcaptureStream（Safariは既存tap）を使い、入力のないエフェクト回路へはフォールバックしない。
- 録画用cloneだけを録画停止時に止める。開始失敗時も作成済みトラックと録音分岐を解放する。

## ウィンドウ音声

本体の2つの共有開始経路を共通化し、`windowAudio: "window"` を要求する。ブラウザーに選択ウィンドウの音声共有を提示してもらうためのヒントであり、共有を強制するものではない。

共有元が音声トラックを返さない場合、表示名に「音声なし」を付ける。この場合は映像のみの録画になり、生成ノイズを元音声の代わりには採用しない。共有を取り直して音声を含める必要がある。対応状況はブラウザー・OS・共有対象に依存する。

仕様: https://www.w3.org/TR/screen-capture/#dom-displaymediastreamoptions-windowaudio
