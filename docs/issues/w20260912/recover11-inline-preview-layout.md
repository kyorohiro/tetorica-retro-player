# 通常表示の初期サイズとAuto Targetの同期

観測: Preview Dialogの通常表示で1〜2セルから広がるような表示と、ときどき重い準備が発生。最大化・Pinでは発生しないとの報告。
原因確定ではなく、コード上の初期レイアウトの不整合を修正する。

- Canvasを生成時から絶対配置にする。既定の300×150の寸法が一時的に親の高さへ影響するのを防ぐ。
- ホストの幅・高さが1px以下の未確定レイアウトではCanvas寸法を更新しない。
- ResizeObserverは次フレームで同じ寸法を確認してから更新を要求する。
- 表示サイズ基準のAuto Targetでは、現在の画像に対応するCanvas表示寸法とTargetが一致するまで画像の転送・描画を待つ。
- Canvasの初期サイジングは現表示領域からの暫定Targetを使用し、前ページのTargetに左右されるのを防ぐ。
- コンパイルの要求・待機処理は維持。600ms遅延表示も再導入しない。

サイズ確定待ち、Render cap、画像の向き変更を自動テスト。実ブラウザーで通常表示のページ送り・最大化・Pin・リサイズを確認する必要がある。
